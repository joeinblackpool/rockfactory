# The Rock Factory Blackpool

Four-page static HTML website for https://rockfactory.uk, using the supplied red, blue and cream logo, historic rock-making imagery and photographs of the units.

## Files

- `dist/index.html`: homepage
- `dist/storage-units-blackpool.html`: personal and business storage
- `dist/offices-to-let-blackpool.html`: two offices at £70 per week each
- `dist/workshops-studios-blackpool.html`: workshops, artist studios and small business units
- `dist/styles.css`: shared responsive styling
- `dist/assets/`: locally hosted, compressed WebP images and the licensed WhatsApp SVG icon
- `dist/sitemap.xml`, `dist/robots.txt`, `dist/404.html`: search and error-page support

Open `dist/index.html` in a browser to use the site locally. Upload the contents of `dist` to the web root for a conventional static host. No framework, build step or JavaScript runtime is needed. Navigation, maps links and accessible FAQ disclosures work with standard HTML.
