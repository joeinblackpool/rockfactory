Prepared 6 October 2026

START HERE

This package contains the latest complete static website, including its editable
HTML and CSS, logo, photographs, WhatsApp icon and search-engine metadata.
The current design uses cream, dark text and selective red and blue accents,
with unframed property photos and an asymmetric historical photo gallery.

1. Unzip this package.
2. Open dist/index.html in a browser to view the homepage locally.
3. Edit the HTML files and dist/styles.css directly.
4. To publish on a conventional static host, upload the CONTENTS of dist to
   the public web root. index.html should be at the domain root, with the
   assets folder beside it. No framework, installation, database, JavaScript
   runtime or build command is required.
5. Configure the host to use 404.html as its error page where supported.

The separate README.md contains content, design and maintenance notes.
All files needed by the website are in dist. Keep their relative paths intact.
